# Semantic Operators and LOTUS — Seminar Slides

Presentation slides and notes for a graduate **Advanced Database Systems** seminar based on the LOTUS paper.

## Paper
- **Title:** Semantic Operators and Their Optimization: Enabling LLM-Based Data Processing with Accuracy Guarantees in LOTUS
- **Authors:** Liana Patel, Siddharth Jha, Melissa Pan, Harshit Gupta, Parth Asawa, Carlos Guestrin, Matei Zaharia
- **Published in:** *PVLDB*, Vol. 18, No. 11, pp. 4171–4184, 2025
- **Official LOTUS Repo:** https://github.com/lotus-data/lotus

## What Is Inside
1. **Part 1: The idea: semantic operators** — Core idea, definitions, example program, operators, and aggregation.
2. **Part 2: Filter and join, made cheaper** — Why filter and join cost a lot, cascade filtering, join plans, and results.
3. **Part 3: Top-k, group-by and the LOTUS library** — Top-k ranking, two-stage group-by, and the LOTUS system.
4. **Part 4: Does it work? Results and limits** — Experiment setup, baseline comparisons, accuracy guarantees, related work, and limits.

## How to Use
- Open `index.html` in a web browser on a computer or iPad.
